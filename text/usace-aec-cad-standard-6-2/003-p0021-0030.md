2.4.3.1  Modeling Area File Naming Convention 
The modeling area file naming convention (Figure 2-3) has three 
mandatory fields, and the fourth is optional. All fields must be in the 
correct sequence. 
Following the Project Code field, the first two-character field represents 
the Discipline Designator. The allowable characters for the Discipline 
Designator are listed in Table 2-1. The second character of the Discipline 
Designator field is typically a hyphen (-), but files may contain multiple 
discipline models so the second character may continue listing disciplines 
located within the file. If there are more than two disciplines, continue 
utilizing the main feature field. The next 8-character (maximum) field 
represents the main modeling feature of the file (e.g., wall, bracing, 
corridor, etc.). The final optional user-definable 15-character (maximum) 
field is available to further describe the file contents.  
It is recommended that the model area file naming schema be documented 
and be consistent for each project.  
Figure 2-3. Modeling area file naming convention. 
 
Note: Although Revit can contain many different area types within one 
file, it is recommended that users use the modeling area file naming 
convention for Revit (.RVT) files.

2.4.4 Sheet File Naming Convention 
The sheet file naming convention (Figure 2-5) contains four mandatory 
fields, and the fifth is optional. All fields must be in the correct sequence. 
Following the project code, the next 2 characters are the Discipline 
Designator with either a hyphen or an alphabetical designator (Table 2-3). 
The next character is the Sheet Type Designator (Table 2-4) followed by a 
2-character Sheet Sequence Number (01–99). Sheet Sequence Numbers do 
not need to be sequential. This allows for future insertion of sheets during 
design. The final field is a 10-character (maximum) user-definable field. 
Figure 2-5. Sheet file naming convention. 
  
When multiple sheets are in the same file, the word “SET” may replace 
either the Sheet Sequence Number (for all sheets under a specific sheet 
type designator) or the Sheet Type Designator and Sheet Sequence 
Number (for all sheets under a specific Sheet Type Designator). 
Alternately, the first and last sheet in a file may be listed as part of the 
user-definable field. The sheet filename shall coincide with the sheet 
identifiers that it contains.
