K-4.  GPS Control Survey Report (CSI Chustz Surveying, Inc.) 
 
Two point pairs were set at each Tract--201A-201B and 317A-317B.  These points were positioned by 2 
hour static GPS observations from a single CORS site in New Orleans (ILSU).  GPS baseline data were 
reduced using Trimble TGO software, and a network adjustment performed in TGO.  The adjusted NAD 
83 SPCS coordinates of point 317A was checked using an OPUS solution that utilized three CORS sites.  
The position difference was less than 0.04 ft.
