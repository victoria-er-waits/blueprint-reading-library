# Step 8 of 9: Build the questions-for-the-engineer list

[Previous: step 7](step-7-cross-checks.md) · [Back to the checklist](../order-of-operations.md) · [Next: step 9](step-9-final-readout.md)

## Goal
Collect every conflict, typo, missing value and NEEDS CHECK into one list a person can send as RFIs. Nothing is resolved by guessing.

## Procedure
1. Gather every item flagged in steps 1-7.
2. One question per issue. Each has: number, sheets involved, what is printed (exact, with sources), why it's a problem, the question, and impact (price, quantity, schedule, safety).
3. Group by discipline and sort by impact (quantities and sizes that change price first).
4. Do not propose an answer as fact. You may add "likely intended" only as a C label.
5. Link each question back to the step-5 records it affects; those records stay C/D until answered.

## Pass / fail check
PASS: every flag from steps 1-7 appears exactly once; each question cites both sources.
FAIL: a conflict resolved silently; a question with no sheet reference.

## Common failures (from real test runs)
- Choosing a value instead of asking (rafter spacing).
- Index/title-block revision mismatch never asked (U5).
- Order of precedence (metric vs imperial set) never asked, so every converted number is uncertain.

## Worked examples
- Good: `Q7 | Sheets 5, 8, 9 | Metric sill height 2,400 mm; imperial 7'-8" (=2,337 mm) | Sets disagree by 64 mm | Which set governs? | Affects window framing`.
- Good: `Q4 | C-05 | Index REV 0 vs title block Rev 1 | Confirm current revision | Affects whole sheet`.

---
Examples come from our own test runs on public municipal tenders and a copyrighted house-plan set used only as a private test. Values are short paraphrases for illustration; no drawings are reproduced. Reference material only, not engineering approval.
