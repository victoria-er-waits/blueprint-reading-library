# Step 4 of 9: Read general notes, legend and abbreviations first

[Previous: step 3](step-3-title-blocks.md) · [Back to the checklist](../order-of-operations.md) · [Next: step 5](step-5-one-sheet-at-a-time.md)

## Goal
Learn the set's own language before reading any drawing: symbols, line types, abbreviations, governing standards and general notes.

## Procedure
1. Find the general notes, legend, symbol and abbreviation sheets (often G-, C-00 or the first sheets of each discipline).
2. Build a dictionary: abbreviation -> meaning; symbol -> meaning; line type -> meaning. Cite the sheet for each.
3. Record governing standards (e.g. MMCD, municipal spec) and which document governs if they conflict (order of precedence).
4. Record general notes that apply everywhere (units, datum, cover depth, materials, "contractor to verify").
5. Note which unit system each sheet uses. If a set has both metric and imperial, record which one governs; if none is stated, that is a question for step 8.
6. Note any exclusions (e.g. "construction safety components not shown").

## Pass / fail check
PASS: a dictionary exists with sheet citations; order of precedence is recorded or listed as a question; units recorded per sheet.
FAIL: you start reading plan sheets and meet an abbreviation that isn't in your dictionary and you guess it.

## Common failures (from real test runs)
- Reading "THK" as a diameter (75 THK insulation read as a 75 pipe) (bug 4).
- Matching words without boundaries: "cros" inside "Cross", "stem" inside "Hollow stem" (bug 7).
- Missing a cover note that excludes safety components, so the read implies they are included (house-plan test).

## Worked examples
- Good: `THK = thickness (sheet G-01 legend)`; `Ø = diameter, units mm unless noted (G-01 note 3)`.
- Good: `Units: metric set and imperial set both supplied; governing set not stated -> Q2`.
- Help: book chapters on symbols and abbreviations, see /index.json (search chapter titles for "symbols", "abbreviations") and images/symbols-legends/.
