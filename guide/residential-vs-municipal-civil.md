# Residential vs municipal civil drawings

The American Farmhouse set (residential architectural) is useful practice, but a municipal tender (watermain, sanitary, roads) reads differently.

## What transfers
- **Title blocks:** sheet number, title, revisions, date and scale all live in a bordered block (here a vertical strip on the right). Learn to find each field by its label, not by position. Every firm's layout is different.
- **Sheet index and numbering:** A0.0 lists every sheet; check the files you received against it. Civil sets do the same (C-101, C-501 ...).
- **Scales:** each view states its own scale; one sheet can hold several. "Do not scale drawings; written dimensions govern" applies to both.
- **Sections and callouts:** bubble number over sheet number (1/A3.1) points to the target view. Same logic as civil detail callouts.
- **Symbols legend and abbreviations:** always read the legend first; abbreviations differ by firm.
- **Schedules and tags:** door, window and fixture marks (F-40 etc.) tie plan symbols to a table, the same way valve/hydrant/structure tags tie to civil schedules.
- **Typical details:** a typical detail is shown once and applies in many places. Don't count it as one more item.

## What does not transfer
- **Plan and profile sheets, stationing and chainage** (0+120.5), inverts, grades and slopes: houses don't have them.
- **Units:** this set is imperial (1/4"=1'-0"). BC municipal work is metric (1:500 plan, 1:50 profile vertical exaggeration, mm pipe sizes).
- **Pipe, utility and survey content:** pipe material/class, bedding, thrust blocks, tie-ins, existing utilities, survey control, road cross-sections.
- **Standards:** civil drawings lean on MMCD / municipal standard details and specs; residential leans on building code and manufacturer data.
- **Quantities:** tender cheat sheets need measured lengths and counts tied to stations; residential sets rarely support take-off like that.
- **Contract documents:** RFQ, addenda and specs govern civil tenders. A house set like this stands alone.

Use the farmhouse set to practise reading conventions. Don't use it to judge accuracy on civil drawings.
