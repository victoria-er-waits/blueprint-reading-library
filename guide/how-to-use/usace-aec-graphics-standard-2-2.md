# How the Blueprint Reader should use: A/E/C Graphics Standard R2.2 (USACE 2023)

Source: https://victoria-er-waits.github.io/blueprint-reading-library/pdf/09-USACE-AEC-Graphics-Standard-R2.2.pdf
Book id: `usace-aec-graphics-standard-2-2`. Full rights note: https://victoria-er-waits.github.io/blueprint-reading-library/catalog.md

## What it teaches
What appears on a sheet: borders and title blocks, orientation (north arrows, grids), symbols, annotation (dimensions, notes, callouts), schedules and revisions.

## Order-of-operations steps it supports

- Step 4: https://victoria-er-waits.github.io/blueprint-reading-library/guide/steps/step-4-notes-legend.md

## What to skip
Introduction and conclusion.

## Pitfalls
- US federal sheet layout; BC title blocks look different but carry the same fields.
- Never quote this book as approval or code for a BC project. The project drawings, specs and legend govern.

## Practice prompts
1. Using Ch 7, list every revision cloud and delta on sheet X and match it to the revision block.
2. Using Ch 4, follow each section and detail callout on sheet X to its target sheet.
