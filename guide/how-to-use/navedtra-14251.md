# How the Blueprint Reader should use: Steelworker Vol 2, NAVEDTRA 14251 (US Navy)

Source: https://victoria-er-waits.github.io/blueprint-reading-library/pdf/06-NAVEDTRA-14251-Steelworker-Vol2.pdf
Book id: `navedtra-14251`. Full rights note: https://victoria-er-waits.github.io/blueprint-reading-library/catalog.md

## What it teaches
Structural steel and rebar: technical drawings for steel, sheet-metal layout, steel terms and fabrication, wire rope, reinforcing steel, pre-engineered structures.

## Order-of-operations steps it supports
- Step 5: https://victoria-er-waits.github.io/blueprint-reading-library/guide/steps/step-5-one-sheet-at-a-time.md
- Step 6: https://victoria-er-waits.github.io/blueprint-reading-library/guide/steps/step-6-sanity-check.md
- Step 7: https://victoria-er-waits.github.io/blueprint-reading-library/guide/steps/step-7-cross-checks.md

## Which part to read for which task
| Task | Read |
|---|---|
| Steel drawings and symbols | Ch 1, PDF pp. 15-44 |
| Structural shapes and connections | Ch 3, pp. 85-132 |
| Rebar sizes, bends, placing | Ch 7 Reinforcing, pp. 187-204 |
| Tables | Appendix II, pp. 325-348 |

Page numbers are PDF page numbers (as in index.json), not printed page numbers.

## What to skip
Sheet metal/fibreglass (Ch 2), airfield matting (Ch 11) and tools (Ch 12) for most civil tenders.

## Pitfalls
- US rebar numbers (#4) vs Canadian metric bars (10M, 15M). Never convert one into the other as equal.
- Steel shapes are US designations; Canadian W-shapes are listed in metric.
- Never quote this book as approval or code for a BC project. The project drawings, specs and legend govern.

## Practice prompts
1. Using Ch 7, read the rebar schedule on sheet X and list bar size, spacing and cover.
2. Check each rebar callout on sheet X against the schedule and flag any mismatch.
