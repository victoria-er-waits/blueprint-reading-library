## What it teaches
Plain-language basics: line types, visualizing 3D from views, sketching, scale, dimensioning, auxiliary and section views, machined features. Mechanical/machine-shop examples.

## Which part to read for which task
| Task | Read |
|---|---|
| Line types (what a hidden, centre, phantom line means) | The Language of Lines, PDF pp. 10-20 |
| Reading views / picturing the object | Visualization, pp. 21-43 |
| Scale | Scaling, pp. 65-70 |
| Dimensions and tolerances | Dimensioning, pp. 71-92 |
| Sections | Sectional Views, pp. 102-115 |
| Putting it together on a real print | Print Interpretation, pp. 132-137 |

Page numbers are PDF page numbers (as in index.json), not printed page numbers.

## What to skip
Technical Sketching (pp. 44-64) unless you must sketch. Machined Features (pp. 116-131) for civil/municipal work.

## Pitfalls
- It is machine-shop oriented (inch, parts). Civil and municipal sets use chainage, elevations and inverts, which it does not cover.
- Title-block examples are for part drawings, not municipal sheet sets.
- Never quote this book as approval or code for a BC project. The project drawings, specs and legend govern.

## Practice prompts
1. Using Costin "The Language of Lines", identify every line type on sheet X and say what each means.
2. Using Costin "Sectional Views", explain what the section cut A-A on sheet X shows and which direction you are looking.
3. Using Costin "Scaling", check whether the stated scale on sheet X matches a printed dimension.
