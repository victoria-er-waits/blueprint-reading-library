Page numbers are PDF page numbers (as in index.json), not printed page numbers.

## What to skip
Nothing; use it as a whole practice set. Only 17 of 25 sheets are here; 8 are held back as an unseen test.

## Pitfalls
- Residential US wood frame, imperial; not a municipal civil set (see guide/residential-vs-municipal-civil.md).
- Share-alike: any adapted output must credit Jay Osborne and keep CC BY-SA 3.0.
- Never quote this book as approval or code for a BC project. The project drawings, specs and legend govern.

## Practice prompts
1. Run steps 1-9 on the farmhouse set and produce a final read-out with A/B/C/D labels.
2. Count every door and window on A1.2-A1.3 and check them against the A5.0 schedule.
3. List every conflict between the sections and the elevations as engineer questions.
