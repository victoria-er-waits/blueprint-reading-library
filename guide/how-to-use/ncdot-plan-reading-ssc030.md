# How the Blueprint Reader should use: NCDOT Plan Reading Course SSC 030 (link only)

Source: https://connect.ncdot.gov/projects/Roadway/RoadwayDesignAdministrativeDocuments/Plan-Reading-Book-Final%20without%20Answers.pdf (link only, not hosted here)
Book id: `ncdot-plan-reading-ssc030`. Full rights note: https://victoria-er-waits.github.io/blueprint-reading-library/catalog.md

## What it teaches
A real roadway plan set course: plan and profile sheets, typical sections, quantities, utility plans. The closest match to municipal civil tenders.

## Which part to read for which task
| Task | Read |
|---|---|
| Plan and profile sheets | profile chapters |
| Quantity tables | summary of quantities chapter |
| Utility plans | utility chapter |

Page numbers are PDF page numbers (as in index.json), not printed page numbers.

## What to skip
NC-specific DOT pay items.

## Pitfalls
- No licence stated: read at the source, never copy into this site.
- US stationing in feet and NCDOT symbols; BC MoTI and city standards differ.
- Never quote this book as approval or code for a BC project. The project drawings, specs and legend govern.
