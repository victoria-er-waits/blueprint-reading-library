# How the Blueprint Reader should use: Engineering Working Drawings Basics (Dr. Ala Hijazi, hosted on NASA SSRI site; link only)

Source: https://s3vi.ndc.nasa.gov/ssri-kb/static/resources/Engineering+Working+Drawing+Basics.pdf (link only, not hosted here)
Book id: `nasa-engineering-working-drawing-basics`. Full rights note: https://victoria-er-waits.github.io/blueprint-reading-library/catalog.md

## What it teaches
22-page summary: sheet layout, title blocks, revision tables, parts lists, views, projection symbols, auxiliary/detail/broken views, dimensioning, line styles, sections, exploded views.

## Order-of-operations steps it supports
- Step 3: https://victoria-er-waits.github.io/blueprint-reading-library/guide/steps/step-3-title-blocks.md
- Step 4: https://victoria-er-waits.github.io/blueprint-reading-library/guide/steps/step-4-notes-legend.md
- Step 5: https://victoria-er-waits.github.io/blueprint-reading-library/guide/steps/step-5-one-sheet-at-a-time.md

## Which part to read for which task
| Task | Read |
|---|---|
| Sheet layout, title block, revision table | first pages |
| Projection symbol (first vs third angle) | views section |
| Dimensioning and line styles | middle section |

Page numbers are PDF page numbers (as in index.json), not printed page numbers.

## What to skip
Exploded and assembly views for civil work.

## Pitfalls
- Not a NASA/US government work: every page reads "Lecture Notes by: Dr. Ala Hijazi" (university course MENG 204). No licence is stated, so it is linked, not hosted.
- Mechanical-part oriented, ISO/ANSI.
- Never quote this book as approval or code for a BC project. The project drawings, specs and legend govern.
