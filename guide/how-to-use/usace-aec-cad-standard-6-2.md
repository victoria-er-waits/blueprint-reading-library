# How the Blueprint Reader should use: A/E/C CAD Standard R6.2 (USACE 2024)

Source: https://victoria-er-waits.github.io/blueprint-reading-library/pdf/08-USACE-AEC-CAD-Standard-R6.2.pdf
Book id: `usace-aec-cad-standard-6-2`. Full rights note: https://victoria-er-waits.github.io/blueprint-reading-library/catalog.md

## What it teaches
How drawing sets are organized: sheet identification and discipline codes, file naming, layers, standard symbology.

## Order-of-operations steps it supports
- Step 1: https://victoria-er-waits.github.io/blueprint-reading-library/guide/steps/step-1-sort-the-set.md
- Step 3: https://victoria-er-waits.github.io/blueprint-reading-library/guide/steps/step-3-title-blocks.md

## Which part to read for which task
| Task | Read |
|---|---|
| Sheet numbering and discipline codes (sorting a set) | Ch 2 CAD File Organization, PDF pp. 13-35 |
| Layers / graphic concepts | Ch 3-4, pp. 36-43 |
| Abbreviations | p. 116 onward |

Page numbers are PDF page numbers (as in index.json), not printed page numbers.

## What to skip
CAD software and layer details if you are reading a PDF, not a CAD file.

## Pitfalls
- US federal convention. BC firms often use their own sheet numbering; the drawing index governs.
- Never quote this book as approval or code for a BC project. The project drawings, specs and legend govern.

## Practice prompts
1. Using Ch 2, decode each sheet number in the index of set X into discipline and sheet type.
2. Flag any sheet in set X whose number does not follow the set's own pattern.
