# How the Blueprint Reader should use: GaugeHow: Learn GD&T and Engineering Graphics (free with signup; link only)

Source: https://gaugehow.com/course/gd-t-geometric-dimension-and-tolerancing (link only, not hosted here)
Book id: `gaugehow-gdt`. Full rights note: https://victoria-er-waits.github.io/blueprint-reading-library/catalog.md

## What it teaches
GD&T: feature control frames, datums, tolerance zones, material condition modifiers, runout/profile, ASME Y14.5-2018 vs 2009.

## Order-of-operations steps it supports
- Step 5: https://victoria-er-waits.github.io/blueprint-reading-library/guide/steps/step-5-one-sheet-at-a-time.md
- Step 6: https://victoria-er-waits.github.io/blueprint-reading-library/guide/steps/step-6-sanity-check.md

## Which part to read for which task
| Task | Read |
|---|---|
| Datums and feature control frames | Datum and Symbols lessons |

Page numbers are PDF page numbers (as in index.json), not printed page numbers.

## What to skip
All of it for municipal civil tenders: GD&T is almost never used on civil drawings. Use it only for machined or fabricated parts.

## Pitfalls
- Needs a free account; bots must not create accounts. A human has to open it.
- Mechanical, not civil.
- Never quote this book as approval or code for a BC project. The project drawings, specs and legend govern.
