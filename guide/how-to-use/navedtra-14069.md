# How the Blueprint Reader should use: Engineering Aid 3, NAVEDTRA 14069 (US Navy 1995)

Source: https://victoria-er-waits.github.io/blueprint-reading-library/pdf/04-NAVEDTRA-14069-Engineering-Aid-3.pdf
Book id: `navedtra-14069`. Full rights note: https://victoria-er-waits.github.io/blueprint-reading-library/catalog.md

## What it teaches
The draftsman/surveyor rating manual: units and maths, drafting conventions, projections, wood frame, concrete, mechanical and electrical drawings, construction drawings, and a full surveying section (linear measurement, horizontal control, levelling, profiles).

Page numbers are PDF page numbers (as in index.json), not printed page numbers.

## What to skip
Ch 15-16 materials testing unless the task is soils/concrete testing. Assignments pp. 673-772 are quizzes.

## Pitfalls
- US stationing 10+00 = 1000 ft; BC chainage 1+000 = 1000 m.
- Check the errata pages before quoting a value.
- Never quote this book as approval or code for a BC project. The project drawings, specs and legend govern.

## Practice prompts
1. Using EA3 Ch 14, explain how the profile on sheet X shows invert elevations and grade, then compute the slope between two manholes.
2. Using Ch 1, convert every metric dimension on sheet X to imperial and flag mismatches with the imperial set.
