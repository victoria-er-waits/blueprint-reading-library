## Public vs private
Public records are stripped of:
- exact expected station ranges and every station value
- key item IDs and key-derived values
- quantities and counts taken from keys
- precision and recall figures
- drawing-location detail and grading evidence

A leak test (`tools/tests`, plus `validate()` in the generator) fails the build on any of these patterns: `key 0+`, `vs key`, `(key …)`, `[key item]`, grading.json field names or the filename itself, P/R numbers and station ranges.

The full records are kept privately, never in this repo, at `/workspace/private-evidence/blueprint-error-memory/` on the operator's box, with mode 700 and sha256 manifests. They are written with `--private-out`, which never overwrites or deletes.

## Regenerate and validate
```
python tools/build_machine_library.py --errors-dir /workspace/blind-runs \
    --private-out /workspace/private-evidence/blueprint-error-memory
python tools/build_machine_library.py --check    # fails if stale, schema-invalid or leaking
python -m pytest tools/tests
```
Requires the `jsonschema` and `pytest` packages.

Error-to-rule links built from regression-test names are exact. Links marked `run_and_page_match_needs_checker_review` are candidates only.
