# Machine-readable Blueprint Training Library (derived; do not hand-edit)

The **source of truth remains `guide/component-rules/hydrants.json`** and Checker's confirmed-errors tables. Everything here is generated by `tools/build_machine_library.py`.

| Path | Contents |
|---|---|
| `schemas/reading-rule.v2.schema.json` | Rule record. Includes `verification_status` (synthetic / nonblind / blind_validated) and `approval`. |
| `schemas/error-memory.v1.schema.json` | Checker-confirmed error record. Key item IDs are redacted (the schema rejects them). It is always flagged `contains graded-run info: never send to Gemini during blind tests`. |
| `schemas/gemini-detection.v1.schema.json` | Gemini assistant output. Suggestions only, with no quantity field. |
| `schemas/manifest.v1.schema.json` | Manifest schema |
| `rules/hydrants.rules.json` | 30 rules in reading-rule/v2 |
| `rules/hydrants.reader-config.json` | A verbatim copy of `reader_config` |
| `error-memory/hydrant-errors.json` | Error records from confirmed-errors-*.md |
| `manifest.json` | Source commit, sha256 of the sources and outputs, and counts |
| `drafts/` | Rule-pack builder spec and Gemini prompt template (drafts, not deployed) |

Regenerate and validate:
```
python tools/build_machine_library.py --errors-dir /workspace/blind-runs
python tools/build_machine_library.py --check    # CI: fails if stale or invalid
python -m pytest tools/tests
```
Requires the `jsonschema` and `pytest` packages.

Provenance rules:
- grading.json files are only hashed, never copied.
- Sealed keys are never read, and the generator refuses a `sealed-keys` path.
- Error-to-rule links say how they were made. `regression_test_name` is exact. `run_and_page_match` is a candidate link and needs Checker review.
- Only BR02-FP-01 is `blind_validated`, based on its general-note exclusion being read correctly in Blind Run 03. Every other rule is nonblind or synthetic.
